# 更新履歴

## 次のリリース

### 使い勝手

- 開いたとき、プロジェクトにフィーチャがあれば全部が入る範囲から始まります（現在位置へは飛びません）。フィーチャが無いときだけ東京から始まり、位置が取れたら現在位置へ移ります
- 等高線は背景地図の 1 つになりました。「地図・タイル」の高度な設定で、標準地図や写真と重ねて使います。標高タイルから等高線のタイルを作って重ね、作ったタイルはキャッシュに残るので二度目からはすぐ出て、圏外でも出ます。間隔は地理院地図に合わせて、寄ると 1 m・引くと 100 m のように自動で変わります。地形の見た目にあった等高線の設定（間隔・色・太さ）はなくなりました

### 使い勝手

- 引いた地図（ズーム 13 以下）では、林班や路線などのフィーチャを地形の絵に描き込む方式にしました。点をまとめたり輪郭を省いたりせず、1 万面あっても軽く回せます。寄せると今までどおり地形に沿った形で描きます
- 設定に「地形の見た目」を足しました。傾斜や標高で地形を色分けでき（色は 3 色を自分で選べます。基図に被せる強さも調整でき、100% にすると基図なしの地形だけになります）、標高タイルから等高線を描けます。色も線も地形の網目から作るので、傾けて横から見ても粗くなりません
- 画面の配置を設定で選べます（自動／縦持ち／横長／左利き）。情報カードは属性テーブルと同じく下から出て、両方は同時に出ません。横長ではカードは右に、左利きではツールバーとボタンが右に寄ります
- CLI や URL から「このプロジェクトを開いて、ここを見せて、読み直して」を頼めるようになりました（`/map?project=…&lat=…&lon=…&zoom=…&reload=1`、`tool/kokage.py`）。地図のメニューに「プロジェクトを読み直す」も付きました
- ラベルの組み立てはスタイル画面（レイヤ／View）に移り、線と面のレイヤでも設定できます。列は値が入っている順に並び、式を直接書くこともできます
- View のスタイルは「レイヤと違う項目だけ」を持つようになりました。レイヤ側を変えると、触っていない項目は View にも届きます。「レイヤに従う」で戻せます
- View が 1 枚だけのレイヤでも View の行を出すようにしました
- 写真の情報カードにも Google Maps のリンクをコピーするボタンを付けました

### QGIS

- ラベルは QGIS と同じ式で持つようにしました（`"列"`、`'文字'`、`concat(...)` など）。`.qgs` には式として書き、QGIS で決めたラベルも読み戻します。これまでの設定はそのまま読み替えます

## v0.7.0 — 2026/09/11

### ⛰ 地図が 3D になりました

- 開くといつもどおり真上からの地図です。1 本指のドラッグで回転と傾き、2 本指で移動と拡大縮小。右上のコンパスをタップすると北を上に・真上に戻ります
- 林班・路線・測点・写真・GPS 軌跡・現在位置・ルームの仲間・オーバーレイ画像（GeoTIFF）が地形の上に載ります。タップでの選択と情報カード、TruPulse の計測も傾けたままできます
- 手で描くとき（ペン・オーバーレイの変形）は自動で真上に固定され、終わると元の傾きに戻ります
- 標高は国土地理院の DEM（1m → 5m → 10m）を優先し、無い所は AWS Terrain Tiles で補います。一度見た範囲は電波の無い場所でも表示できます
- 地形の陰影は光の向きではなく傾斜の濃淡です。急な斜面ほど濃く、尾根と谷底が白く抜けます
- コンパスを長押しすると「眺めモード」。遠近のある眺めになり、遠くは靄に溶けます。もう一度長押しで戻ります
- 描画は GPU で行うので、回転や傾きの最中も滑らかです
- ツールの切替と同じように、眺めモードや北上・真上に戻したときも画面中央に短く表示します

### web

- web も同じ 3D の地図で開きます。描画は WebGL2 で、こちらも GPU です。操作は Android と同じで、マウスは左ドラッグで移動、右ドラッグ（または Ctrl + 左）で回転と傾き、ホイールで拡大縮小です

### 修正

- 初めてのインストールで、位置情報の許可を押した直後にアプリが終了することがあったのを直しました

## v0.6.1 — 2026/09/07

v0.6.0（4/16）以降の変更をまとめました。

### 🌳 名称を「こかげマップ」に統一

- 「RootMap GIS」「K-Maps」と場所で違っていた呼び名を「こかげマップ（Kokage Map）」に一本化し、画面内の旧名称も直しました
- ⚠ Drive の連携フォルダ名 `RootMap GIS Projects` はそのままです（変えると連携済みフォルダを見失うため）

### 🌐 web版（Chrome / Edge）

- ブラウザでプロジェクトフォルダを開き、GeoPackage の表示・編集、Google Drive 連携（クローン・アップロード・ダウンロード）、位置共有パーティが使えます。前回開いたフォルダを覚えます
- ⚠ Firefox / Safari はフォルダを開けず、背景地図の表示のみ。フォルダ名の変更とグローバルフォルダの設定は web 版にはありません。位置精度は端末の GPS より粗いので、現場では Android 版を使ってください
- Windows / macOS / Linux 版は終了し、web 版に一本化しました（配布は URL。PWA としてインストールできます）

### 🔍 View と、レイヤ／View ごとのスタイル

- 1 つのレイヤに、条件（SQL の WHERE 句。QGIS のフィルタと同じ書き方）の違う見せ方「View」を何枚も作れます。レイヤのメニューから「View を追加」
- レイヤ／View ごとに色・太さを変えられます。⚠ これまでレイヤ単位のスタイルは保存されるだけで地図に出ていませんでした。今回から反映されます
- ⚠ 重なり順はまだフォルダ構成どおりになりません

### 🗺 QGIS 連携

- フォルダごとに `<フォルダ名>.qgs` を自動で書き出し、表示の切り替えやスタイル変更に追従します。QGIS 側で設定した印刷レイアウトやシンボルの細部は消しません（分類・ルールベースのスタイルには触りません）
- QGIS で `.qgs` を保存すると、次にプロジェクトを開いたときに View・スタイル・表示状態を読み込みます。`.qgz` も読めます
- Drive 連携などの設定を持つサブフォルダは自分の `.qgs` を持ち、親のプロジェクトには埋め込みで載ります。サブフォルダ単体を渡しても QGIS で開けます
- こかげマップで編集した GeoPackage を QGIS でそのまま使い続けられるよう、空間インデックス・範囲・件数の記録を保存時に整えます
- ⚠ QGIS での実開封は未確認です。開かない場合はお知らせください

### 👥 位置共有パーティ

- 招待リンクと QR コードで参加できます（リンクを開くとブラウザ版の参加画面が開きます）
- 圏外だった仲間の道のりが、電波復帰時にまとめて届いて薄い線で表示されます
- ホストがメンバーを退出させられます
- Drive 連携フォルダも QR コードで渡せます（受け取る側は「フォルダを追加」→「QR コードをスキャン」。サーバーは要りません）

### 📍 GPS・写真（Android）

- GPS 軌跡などのグローバルフォルダを `Documents/KokageMap/Global` に移し、アプリを削除しても消えなくなりました。初回起動時に自動で移します（旧フォルダは `k_maps_global.migrated` として残ります。消して構いません）
- 現在位置が画面の外にあるとき、その方向を示す矢印が画面の縁に出ます。タップで現在位置へジャンプ
- 写真を追加しても位置情報・撮影方向・元のファイル名を保持します（「すべてのファイルへのアクセス」を許可していない端末でも）。保持できなかった写真があれば通知でお知らせします。⚠ クラウドにしかない写真は位置情報が取れません
- Android 13 以降で「GPS 取得中」「位置共有中」の通知が出るようになりました（通知の許可を求めます）。起動のたびに「付近のデバイス」の許可を求めるのはやめました

### 🗾 背景地図・そのほか

- 初期状態の背景地図を国土地理院（標準地図）に変えました。OpenStreetMap の「Access blocked」は直りましたが、一括ダウンロードは利用規約により使えません（残った画像は 設定 → 背景地図 → キャッシュクリア で消えます）
- 起動時に現在地へ移動しないことがある問題、地図が目的地の手前で止まる問題、パーティのダイアログが画面からはみ出す問題を修正しました
- レイヤ一覧と属性テーブルの背景を不透明にしました（航空写真で文字が読みづらかったため）
- 内部の整理: 使われていないコードの削除、地図画面と座標系まわりの再構成、静的解析の強化

## v0.6.0 — 2026/04/16

### 📐 水準器機能を追加

- 全画面の水準器画面を新規追加（地図画面のAppBarからアクセス）
- 加速度計・コンパス・GPSを統合した水準器ツール
  - 大きな円（球体見立て）内で流動点が球面正投影に基づいて移動（sin(θ)）
  - 中心点と流動点を結ぶ線分に角度をリアルタイム表示
  - N/E/S/Wが円周を回転して常に北を指すコンパス表示
- 情報パネルに各種データを表示
  - GPS座標（緯度・経度）、標高、精度
  - 方位角、Pitch/Roll角度、コンパス精度インジケータ
  - 直角三角形の計算と図示（タップで基準辺を切り替え可能）
- 水平判定時に触覚フィードバック、色による状態表示
- ポートレート/ランドスケープ両対応のレスポンシブレイアウト

### 🌍 あらゆる座標系のGeoPackageに対応

- QGIS等で作成された任意のEPSGコードのGeoPackageを読み込み・編集可能に

- 読み込み時にWGS84へ自動変換、書き込み時にソースCRSへ逆変換

### 🔧 外部GeoPackageとの互換性改善

- QGIS/GeoPandasが生成するSpatiaLiteトリガー（ST_IsEmpty等）を書き込み直前に検出・除去

- GPBinaryヘッダーのsrsIdが常に4326にハードコードされていた問題を修正

### 📡 GPS軌跡の表示最適化

- GPS軌跡の記録・表示をハイブリッド方式に刷新
  - 未反映分はメモリキャッシュからリアルタイム表示、反映済み分はGPKGレイヤツリー経由で表示

  - 輝度→透明度: 明るい部分を透明、暗い部分を不透明に（グラデーション）
  - 透明/不透明に分離: 閾値で完全透明か完全不透明に分ける（色は維持）
  - 白黒2値化＋白を透明化: 白黒に変換し、白い部分を透明にする
- 変換後のファイル名をダイアログで指定可能

### ⚡ パフォーマンス改善

- オーバーレイ画像の変形操作（平行移動・拡縮・回転）のレスポンスを大幅に改善
  - ハンドルUIは即時更新、MapLibreへの反映は100msデバウンスで間引き
  - 毎フレームの重いソース再構築を回避

### 🐛 バグ修正

- オフライン環境でオーバーレイ画像が表示されない問題を修正
  - Android: ローカルHTTPサーバー経由ではなくfile://で直接読み込むように変更（MapLibre Nativeがサポート）
  - オフライン時にlocalhostへの通信がOSレベルで遮断される問題を回避
