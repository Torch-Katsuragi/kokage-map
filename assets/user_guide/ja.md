# こかげマップ ユーザーガイド

このガイドでは、こかげマップの基本的な使い方を説明します。

---

## はじめに

### アプリを起動する

1. こかげマップを開くと、ホーム画面が表示されます。
2. 初回起動時は、ストレージ・位置情報・Bluetoothの権限を求められます。画面の指示に従って許可してください。
3. :icon-map: 「地図を開く」をタップすると、いつもの地図が開きます。フォルダを選ぶ必要はありません。

### いつもの地図

「地図を開く」で開くのは、端末の `Documents/KokageMap` フォルダです。中身は次のとおりです。

- **マイ地図.gpkg** — 書き込み先。点・線・面のレイヤを最初から用意してあります。
- **共有** — QR で受け取った地図が入ります。
- **KokageMap.qgs** — フォルダの設定。PC の QGIS でこのファイルを開くと、アプリと同じ見た目で開けます。

アプリが使うフォルダ（グローバルフォルダ・チュートリアルの練習用）は、中の隠しフォルダ `.kokage` にあり、地図には出ません。

### ほかのフォルダを開く

:icon-folder_open: 「フォルダを選んで開く」で、いつもの地図の中のフォルダ（「共有」で受け取った地図など）を 1 つ選び、それだけを地図として開けます。フォルダをタップすると中に入り、「＜」で戻ります。右上の「新しいフォルダ」でフォルダを作れます。中の GeoPackage（.gpkg）は自動で認識されてレイヤーとして表示されます。いつもの地図の外にあるフォルダは、右上のメニューの「端末の別の場所…」から選べます。最後にほかのフォルダを開いていたときは、ホームに「続きから」が出ます。

## 地図画面のUI構成

地図画面は以下の要素で構成されています：

- **左端**: ツールバー（縦並び）— ツールの切り替え
- **上部**: AppBar — プロジェクト名、通知ベル :icon-notifications:、設定 :icon-settings:、属性テーブル :icon-table_view:、レイヤーパネル :icon-layers:
- **右側**: レイヤーパネル（:icon-layers: ボタンで開閉）
- **下部**: 属性テーブル（:icon-table_view: ボタンで開閉）
- **左下**: GPS測量ボタン（GPSツール選択時）、消しゴムFAB（ペンツール時）
- **右下**: 描画確定ボタン（描画中・GPS測量中に表示）

## 地図の操作

### 基本操作

| 操作 | 方法 |
|------|------|
| 地図を移動する | 指1本でドラッグ（:icon-pan_tool_alt: てのひらツール選択時）|
| ズームする | 2本指でピンチイン/ピンチアウト |
| 回転する | 2本指で回転 |

> ペンツール :icon-edit: 選択中でも、**2本指操作**で地図の移動・回転・ズームが可能です。

### 背景地図を変更する

1. AppBarの :icon-settings: 設定ボタンをタップします。
2. :icon-map: 「背景地図」カテゴリを選択します。
3. 使いたいタイルソース（OpenStreetMap、地理院タイルなど）を選択します。

### オフライン地図を準備する

1. 設定画面 → :icon-map: 「背景地図」を開きます。
2. 「一括ダウンロード」を使うと、指定した範囲とズームレベルのタイルをまとめて保存できます。
3. ダウンロードしたタイルはオフライン時に自動的に使用されます。

## レイヤー管理

### レイヤーパネルを開く

地図画面のAppBar右端にある :icon-layers: ボタンをタップすると、**右側にレイヤーパネル**が開きます。もう一度タップすると閉じます。パネル幅はドラッグで調整できます。

### レイヤーの構造

レイヤーパネルには以下の階層構造が表示されます：

- :icon-folder: **フォルダ** — プロジェクトフォルダ内のサブフォルダに対応
- :icon-table_chart: **GeoPackageファイル** — フォルダ内の.gpkgファイル。小さい見出しで表示され、押すと中のレイヤーを畳めます
- :icon-layers: **レイヤー** — GeoPackageファイル内のデータレイヤー（ポイント、ライン、ポリゴン）。左端の印は地図での色、名前の横の数字は件数です

一番上には今いるフォルダの名前と、その上の道筋が出ます。道筋の名前を押すと、その階層へ戻れます。

### メニューを開く

フォルダ・GeoPackage・レイヤー・写真の行を**長押し**（パソコンでは右クリック）すると、名前の変更・スタイル・削除などのメニューが出ます。
- :icon-photo: **写真** — フォルダ内の画像ファイル

### 新しいレイヤーを作成する

1. レイヤーパネルのタイトルバーにある追加ボタンから作成できます。
2. 「GeoPackage」でファイルを新規作成します。既存のGeoPackageにレイヤーを足すときは、GeoPackageの見出しを長押しして「レイヤ追加」を選びます。
3. ジオメトリタイプ（MultiPoint / MultiLineString / MultiPolygon）とレイヤー名を入力して作成します。

### レイヤーの表示/非表示を切り替える

レイヤーパネルで、行の右端にある :icon-visibility: をタップすると、表示 :icon-visibility: と非表示 :icon-visibility_off: を切り替えられます。フォルダやGeoPackageファイルの目でまとめて切り替えることもでき、そのときは中のレイヤーが灰色になります。

### レイヤーの順序を変更する

レイヤーパネル内で、レイヤーを長押ししたまま動かすとドラッグ＆ドロップできます（動かさずに離すとメニュー）。別のGeoPackageにドロップすれば、レイヤーの移植も可能です。

### グローバルフォルダを使う

:icon-folder_special: グローバルフォルダはプロジェクトに依存しない共有フォルダです。どのプロジェクトを開いても、レイヤーパネルの「System」の下に表示されます。GPS履歴や共有データの保存に便利です。既定の場所は `Documents/KokageMap/.kokage/Global` で、設定画面の「一般」カテゴリからパスをカスタマイズできます。

## 描画・編集

### ツールの種類

地図画面の**左端**にあるツールバーから、以下のツールを切り替えて使えます：

| ツール | アイコン | できること |
|--------|----------|------------|
| てのひら（パン） | :icon-pan_tool_alt: | 地図の移動・ズーム |
| ペン | :icon-edit: | ポイント・ライン・ポリゴンの描画 |
| 選択 | :icon-select_all: | フィーチャの選択・編集 |
| GPS測量 | :icon-gps_fixed: | GPSを使ったポイント・ライン・ポリゴンの作成 |

外部計測機器（TruPulse等）が接続されると、ツールバーに追加のツールボタンが動的に表示されます。また、オーバーレイ画像を選択中は :icon-transform: 変形ツールも表示されます。

### ポイントを追加する

1. :icon-edit: ペンツールを選択します。
2. レイヤーパネルでポイントレイヤーをタップして選択状態にします。
3. 地図上の追加したい位置をタップすると、ポイントが追加されます。
4. ドラッグすると、描いた軌跡に沿ってポイントが作成されます。

### ラインを描画する

1. :icon-edit: ペンツールを選択します。
2. ラインレイヤーが選択されていることを確認します。
3. 地図上を**ドラッグ**するとフリーハンドで描画できます。指を離すとラインが確定してフィーチャとして保存されます。
4. **タップ**で頂点を1つずつ追加することもできます。この場合は右下の :icon-check: 確定ボタンで保存します。

### ポリゴンを描画する

1. :icon-edit: ペンツールを選択します。
2. ポリゴンレイヤーが選択されていることを確認します。
3. 地図上を**ドラッグ**してフリーハンドで描くと、指を離した時点で自動的にリングが閉じられ、ポリゴンとして保存されます。
4. **タップ**で3点以上タップした後、:icon-check: 確定ボタンで保存することもできます。

### 消しゴム機能

:icon-edit: ペンツール選択中に、左下の :icon-delete: 消しゴムFABボタンを押した状態でフィーチャをタップまたはドラッグすると、触れたフィーチャが削除されます。

### フィーチャを選択する

1. :icon-select_all: 選択ツールを選択します。
2. 地図上のフィーチャをタップして選択します。同じ場所を連続でタップすると、重なっているフィーチャを**優先度順にサイクル**選択できます（ポイント > ライン > ポリゴンの順）。
3. ドラッグすると**投げ縄選択**ができ、囲んだ範囲内のフィーチャをまとめて選択できます。

### スタイラス（ペン入力）とタッチ入力

こかげマップはスタイラスとタッチ入力を区別します：

- **スタイラス（ペン）**: フリーハンド描画に使用
- **タッチ（指）**: ポイント追加や地図の操作に使用

PC版ではマウスホイールでズーム、中ボタンドラッグで地図移動ができます。

## GPS機能

### GPS測量でポイントを記録する

1. :icon-gps_fixed: GPSツールを選択します。
2. 左下に表示される :icon-add_location: 記録ボタンをタップすると、現在のGPS位置にポイントが追加されます。
3. **長押し**すると、複数のGPSデータを収集して位置を平均化し、精度を向上させることができます。長押し中は収集したデータ数がリアルタイムで表示されます。

### GPS測量でライン・ポリゴンを作成する

1. :icon-gps_fixed: GPSツールを選択し、ラインまたはポリゴンレイヤーを選択します。
2. :icon-add_location: 記録ボタンをタップ（または長押し）するたびに、GPS位置が測量点として蓄積されます。
3. 測量点が蓄積されると右下に :icon-check: 確定ボタン、:icon-undo: 取消ボタン、:icon-clear: キャンセルボタンが表示されます。
4. 確定すると測量点からライン/ポリゴンフィーチャが作成されます。

### GPS軌跡を抽出する

GPSツール選択中に左下の :icon-timeline: 軌跡抽出ボタンをタップすると、過去のGPS位置履歴から日付・時間範囲を選択してラインレイヤーに保存できます。

### 外部GNSS機器を接続する

1. 設定画面 → :icon-bluetooth_connected: 「計測機器」を開きます。
2. Bluetooth接続可能な高精度GNSS受信機を選択して接続します。
3. 接続すると、外部機器からの位置情報が自動的にGPS測量に使用されます。

## 属性テーブル

### 属性テーブルを開く

地図画面のAppBarにある :icon-table_view: ボタンをタップすると、**画面下部に属性テーブル**が表示されます。現在選択中のレイヤーの属性データが表示され、選択レイヤーを変更すると自動的に切り替わります。

### 属性を編集する

属性テーブルの各セルをタップして、値を直接編集できます。テキスト、数値などを入力可能です。

### フィルタ・検索・置換

- **フィルタ**: QGIS式フィルタで条件式によるデータの絞り込みができます（例: `"面積" > 100`）。
- **検索・置換**: 属性値の検索と一括置換が可能です。
- **フィールド計算機**: SQL式で属性値を一括計算・更新できます。

### カラム操作

- :icon-add: カラムの追加（テキスト・整数・小数・バイナリ型）
- カラム名の変更・削除
- カラムの表示/非表示切り替え

### その他の機能

- CSVエクスポート
- テーブルデータのクリップボードコピー
- フィーチャの追加・削除
- フィルタ結果の複製（新しいレイヤーとしてコピー）
- 一括編集（チェックした行の値を一括変更）

## データのインポート・エクスポート

### ファイルをインポートする

以下の形式のファイルをインポートできます：

- **Shapefile** (.shp + .shx/.dbf/.prj)
- **GeoJSON** (.geojson / .json)

レイヤーパネルのGeoPackage内にインポートされます。GeoJSONの場合、ジオメトリタイプごとに自動でレイヤーが分割されます。

### レイヤーをエクスポートする

1. レイヤーパネルでエクスポートしたいレイヤーを長押ししてメニューを開きます。
2. :icon-file_download: 「エクスポート」を選択します。
3. 出力形式を選びます：
   - **Shapefile** (.shp) — 座標系（EPSG）の選択が可能
   - **GeoJSON** (.geojson)
   - **CSV** (.csv)
   - **KML** (.kml)
4. 保存先を指定して出力します。

## 写真管理

### ギャラリーから写真をインポートする

1. レイヤーパネルのタイトルバーにある :icon-photo: 「写真」ボタンをタップします。
2. ギャラリー（ファイルピッカー）から写真を選択します。
3. 写真はプロジェクトフォルダにコピーされます。EXIF情報に位置データがあれば、地図上にマーカーとして自動表示されます。

### 写真をオーバーレイにする

写真をオーバーレイに変換すると、地図上に画像を重ねて表示できます。レイヤーパネルで写真のメニューから「オーバーレイに変換」を選択します。オーバーレイは :icon-transform: 変形ツールで移動・回転・拡縮できます。

## Google Drive連携（Android）

### QR で地図を受け取る

1. 渡す側は、Drive連携フォルダのメニューから「QRコードで渡す」を選びます。
2. 受け取る側は、スマホのカメラで QR を読みます。こかげマップが開いて、いつもの地図の「共有」に地図を取り込み、その場所を表示します。
3. ホームの「QR で受け取る」から、アプリのカメラで読んでも同じです。
4. 初めてのときは Google へのログインが求められます。
5. 同じ QR を読み直すと、取り込み済みの地図を開くだけです。こかげマップが入っていないスマホやパソコンで読むと、入れ方の案内が開きます。

### Drive連携フォルダを追加する

1. レイヤーパネルで「新規フォルダ」→ :icon-cloud: 「Google Driveクローン」を選択します。
2. Google Driveの共有URLを貼り付けるか、QRコードをスキャンします。
3. Googleログインが求められたら認証します。
4. フォルダの内容がローカルにクローンされます。

### データを同期する

1. Drive連携フォルダのメニューまたはタイトルバーの同期ボタンを使います。
2. アップロード（ローカル→Drive）またはダウンロード（Drive→ローカル）を選択して同期します。
3. 同期状態はアイコンで確認できます（同期済み / ローカル変更あり / Drive変更あり / 競合あり）。

> **PC版**ではGoogle Drive Desktopでの同期を推奨しています。アプリ内のDrive連携はAndroid専用です。

## 測量機器連携（TruPulse）

### TruPulseレーザー測距計を接続する

1. 設定画面 → :icon-bluetooth_connected: 「計測機器」を開きます。
2. AndroidのBluetooth設定でTruPulseをペアリングします。
3. デバイスリストからTruPulseを選択して接続します。
4. 接続すると、地図画面のツールバーに :icon-explore: コンパスツールが自動的に追加されます。

### 測量データを取得する

1. ツールバーのコンパスツールに切り替えます。
2. TruPulseで測定すると、距離・方位角・傾斜角のデータがリアルタイムで送信されます。
3. 現在のGPS位置を基準に、測定結果からポイント位置を計算して記録します。

### 閉合測量を行う

複数のポイントを測量し、ライン・ポリゴンに変換できます：

- **閉合比**がリアルタイムで表示されます
- **コンパス法則（Bowditch法）** / **トランシット法則**で閉合補正が可能
- **磁気偏角補正**（WMM2025から自動算出）
- **器械高・目標高補正**
- **後視補正**（バックサイト自動計算）

## 設定

AppBarの :icon-settings: 設定ボタンから設定画面を開けます。設定画面はレスポンシブなSplit View形式で、左にカテゴリ一覧、右に詳細設定が表示されます。

| カテゴリ | アイコン | 設定内容 |
|----------|----------|----------|
| 一般 | :icon-settings: | 言語設定、UIサイズ調整（7段階）、グローバルフォルダパス、権限管理 |
| 背景地図 | :icon-map: | タイルソースの選択、オフラインキャッシュ管理 |
| GPS | :icon-gps_fixed: | GPSソースの選択・テスト、外部GNSS設定 |
| 計測機器 | :icon-bluetooth_connected: | Bluetooth機器の接続設定（Android） |
| レイヤースタイル | :icon-palette: | ポイント・ライン・ポリゴンの表示スタイル（色、太さ、クラスタリングなど） |
| 同期 | :icon-sync: | Google Drive自動同期設定（Android） |
| フィードバック | :icon-feedback: | バグ報告・機能リクエスト |
| アプリ情報 | :icon-info_outline: | バージョン情報、ライセンス表示 |

### 言語を変更する

設定画面で「一般」カテゴリを選択し、言語設定を変更します。日本語 / English から選択でき、即座に切り替わります。

### UIサイズを調整する

設定画面で「一般」カテゴリを選択し、スライダーで7段階（XS / S / M− / M / M+ / L / XL）から選べます。テキストやUI要素のサイズが即座に反映されます。

## トラブルシューティング

### :icon-warning: 地図が表示されない

- インターネット接続を確認してください。
- オフライン地図のキャッシュをダウンロードしてみてください。

### :icon-warning: GPSが取得できない

- 位置情報の権限が許可されているか確認してください（設定画面 →「一般」→ 権限管理）。
- 屋外で空が開けた場所で試してください。
- 外部GNSS機器を使用する場合は、Bluetooth権限も必要です。

### :icon-warning: ファイルが開けない

- ストレージの権限が許可されているか確認してください。
- インポート対応形式は **Shapefile** と **GeoJSON** です。
