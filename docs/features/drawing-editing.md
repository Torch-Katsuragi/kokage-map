# 描画・編集機能

## 基本図形描画

- **点 (Point)**: タップで配置。アイコンや色のカスタマイズ。
- **線 (LineString)**: フリーハンド描画、タップによる頂点指定。太さ、色、線種の変更。
- **領域 (Polygon)**: フリーハンド描画、タップによる頂点指定。塗りつぶし色、透過度、境界線の設定。

## 属性情報編集

- 描画した地物（フィーチャ）ごとに、テキスト、数値、写真などの属性情報を簡単に入力・編集。写真は [[feature-photos]]
- 事前に定義した属性スキーマ、または自由形式での入力。

## 編集ツール

- 選択ツール
- 移動ツール
- 頂点編集ツール
- 削除ツール
- 元に戻す/やり直し (Undo/Redo)

## 計測ツール

2026-10-11 に入れた。左のツールバーの定規（`lib/tools/measure_tool.dart`）。地物は作らない。

- タップで点を置き、区間ごとの距離と合計を出す。1 点戻す・消すはパネル（左上）から
- 面にするのは左下のボタン（ペンの消しゴム・選択の複数選択と同じ `isFabActiveProvider`）か始点のタップ。
  切り替えは中央に名前を出す（`ToolNameFlash` がツールとボタンの組から「距離を測る／面積を測る」）
- 1 本指を取らないので、3D でも傾け・回転はいつもどおり。タップは `MapSurface.unproject`（`MapSurfaceController.toLatLng` 越し）を通り、空や地図の外は無視する（`IMapState.tryOffsetToLatLng`）
- 線と点は地図の場面に焼かず、カメラが動くたびに描き直す（編集の重ね絵と同じ。`measure_overlay.dart`）。ほかのツールに替えると消える

## 長さ・面積の測り方

`lib/utils/geodesic.dart` に一本化した（情報パネル・複数選択の合計・計測ツール・ペンの描きかけ・編集中の寸法）。

- 長さは WGS84 楕円体の Vincenty。面積は正積緯度で等積の球に移して球面多角形で測る。pyproj（Karney）と 0.01% 以内（`test/geodesic_test.dart`）
- turf は半径 6378137 m の球なので、北緯 34° で面積が 0.3% ほど大きく出ていた
- 投影座標系のレイヤも読み込み時に WGS84 へ直してあるので、同じ式で測れる
- 情報パネルは見出しの下に、線は長さ、面は面積（m²・ha）と周長（穴の周も足す）。`infoMap` の `area` / `length` はやめた（同名の属性列を上書きしていた）

## 属性で探す

レイヤ一覧のタイトルバーの虫眼鏡（`lib/widgets/feature_search_dialog.dart` → `lib/services/feature_search.dart`）。

- 見えているレイヤ（消灯した View の地物は出さない）の属性を、レイヤごとに SQLite の LIKE で探す。列をつないだ 1 本に、
  打った語の表記ゆれ（全角・半角、大文字・小文字、ひらがな・カタカナ・半角カナ）の数だけ LIKE を当てる
- 値がそのまま一致する行を先に並べてから上限（レイヤごと 200 行、全体 100 件）で切る。当たった行は正規化して照らし直し、一致 → 前方一致 → 部分一致の順
- ⚠ 1 つの値の中で全角と半角が混ざっている（「第１2林班」）と LIKE の段で漏れる
- 押すと選んで、形が収まるよう寄せる（点は 17 まで寄る）

## 入力デバイス対応

- 地図操作ツール（MapTool）を導入し、「てのひら」「ペン」「選択」などのツールを切り替え可能。
- ペン入力（スタイラス）とタップ入力（指・マウス）で挙動を分岐し、ペンはフリーハンド描画、タップは点追加や選択など直感的な操作性を実現。
