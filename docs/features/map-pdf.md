# 地図の PDF 出力（簡易）

今見ている地図を 1 ページの PDF にする。森林組合への提出や現地説明の配り物向け。入口は ≡ メニュー →「地図を PDF に」（2026-10-11）。

## 紙面

- 用紙は A4・A3、向きは横・縦。前回の選択はアプリを開いている間だけ覚える
- 表題（既定はプロジェクトのフォルダ名）・日付・地図・縮尺（1:5,000 など）と縮尺記号・方位記号・凡例・備考・背景地図の出典
- 横向きは右に、縦向きは下に凡例と備考の欄。凡例も備考も無ければ地図が広がる
- 凡例は紙の地図に掛かるレイヤだけ（地物の範囲で判定）。単一シンボルは 1 行、View があれば見出しの下に View ごと、QGIS の描き分けなら見出しの下に描く項目だけ。色見本は `QgisSwatchPainter`（レイヤ一覧の凡例と同じ）
- 出典は見えている背景地図のもの。等高線は標高タイルから作るので標高タイルの出典。地理院タイルは出典の明示が利用条件

## 縮尺・方位

- 範囲: 画面の地図（論理 px × ズーム）が地図枠に収まる縮尺を、切りのよい分母（1・1.5・2・2.5・3・4・5・6・8 × 10^k）に丸める
- 真上から描く。3D で傾けていても傾きは見ない（中心・ズーム・方位だけ使う）
- 方位は画面のまま。Web Mercator の経線は紙の上で縦なので、地図を回した角度だけ回せば方位記号は真北を指す
- 縮尺記号は中心を通る東西の線で紙の長さぶんの地上距離を測地線（Vincenty）で測り、1・2・5 × 10^k m の切りのよい長さにする
- 線の太さ・点・ラベルは画面の 1 論理 px = 紙の 0.2 mm

## 描き方

- 地図の絵は地図面の窓口「スナップショット」（`MapSurface.snapshotTopDown`）。地形のテクスチャと同じ合成
  （背景地図の層 → オーバーレイ画像 → 地物。`RasterTileComposer.composeLayers` + `paintFeatures`）で、紙の 1 px にタイルの 1 px が届く段のタイルを敷き詰める。
  回した枠の外接矩形を覆い、一辺 16 枚（4096 px）を超えるなら段を下げる。タイルの画像キャッシュは使わない（画面の絵を追い出さない）
- ラベルは紙に合わせて立てて、絵の後に描く（重なりは先勝ちで間引く）
- 紙面は 200 dpi（A3 横で 3307 × 2339 px）で dart:ui の Canvas に描き、1 枚の画像として PDF（`pdf` パッケージ）に入れる
- 保存は他の書き出しと同じ `FilePicker.saveFile`（bytes を渡す。Android は保存先の選択、web はダウンロード）

> [!NOTE] 日本語のフォントを同梱しない
> 文字は端末のフォントで画像に描く。`pdf` パッケージは TrueType しか埋め込めず、Android の CJK フォントは CFF（.ttc）なので使えない。
> Noto Sans JP を同梱すると APK が数 MB 増える。その代わり PDF の文字は選択・検索できない（表題は PDF の文書情報に入る）

## 未対応

- 現在位置・GPS 軌跡・選択・写真の印・ルームの人とピン・地形の色分け（傾斜・標高）は入らない
- 縮尺の指定・範囲の手動調整・複数ページ
- web で A3 を作ると、圧縮（pure Dart の zlib）に数秒かかる
