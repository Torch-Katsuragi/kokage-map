# UI/UXの方向性

## ツールバー/パレット

- 画面の端（左側や下部など）に、描画ツール（ペン、消しゴムなど）、選択ツール、カラーピッカーなどを配置。
- Adobe Frescoのように、選択中のツールに応じてオプションが変化するコンテキストメニュー。

## レイヤーパネル

- 画面の反対側の端に、階層的なリストを表示。
- プロジェクトのフォルダ構造をトップレベルのグループとして反映。
- 各フォルダグループ内には、サブフォルダグループや、そのフォルダ直下のGeoPackageファイルを表す「GeoPackageソース」アイテムが表示される。
- 「GeoPackageソース」アイテムは展開可能で、内部のレイヤーを表示・管理できる。
- ドラッグ＆ドロップでの並べ替え、スワイプでの表示/非表示など、直感的な操作。
- 画面の端に地図操作ツールバーを配置し、「てのひら」「ペン」「選択」などのツールを切り替え可能。

## ジェスチャー操作

- ピンチイン/アウトでのズーム。
- 2本指ドラッグでのパン。
- 長押しでのコンテキストメニュー表示など。

## ビジュアル

- シンプルでクリーンなデザイン。
- アイコンは分かりやすく、視覚的に魅力的なものを使用（フォルダ、GeoPackageファイル、各種レイヤータイプなど）。
- ダークモード対応。
- 地図操作ツールのアイコン（てのひら・ペン・選択など）を明示的に表示。
- ペン入力とタップ入力で挙動が異なることをUI上で分かりやすく表現。
