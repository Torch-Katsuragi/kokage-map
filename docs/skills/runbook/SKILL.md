# Runbook Skill

定型的なタスクやリリースフローを、事前に定義された手順書に従って実行します。

## 実行ワークフロー

1. ユーザーからのリクエスト（例：「内部テストリリースを実行して」）を解析します。
2. 下記の「キーワードマッピング」を確認し、該当する手順書（`.md`ファイル）のローカルパスを特定します。
3. `view_file` ツールを使用して、該当手順書を読み込みます。
4. 手順書に記載されたステップを**必ず順番に（一つずつ、またはまとめて可能なものは）**実行します。
5. 手順の途中でユーザーの介入が必要な場合は、明示的にターンをユーザーに渡し、完了を待ちます。

## キーワードマッピング

| キーワード | 手順書ファイルパス | 概要 |
| --- | --- | --- |
| `内部テストリリース` `クローズドテストリリース` `Playにアップ` | `.claude/skills/runbook/procedures/internal_test_release.md` | AAB を Play Developer API でアップロードしトラックに割り当てる（内部/クローズド共通） |
