# 用途プリセットとUI引き算の設計（Role Presets）

際限なく機能や公式データを追加しても「センスの良い使いやすいアプリ」を保ち続けるため、現場ごとの役割に合わせて **UI（道具・ボタン・メニュー）・背景地図・公式データ・3D地形精度・GNSS/軌跡設定・オフライン取得範囲** を一括で整える「引き算の設計」を導入している。

---

## 1. 設計思想（固定ロックではなく「一括レシピ＋個別調整」）

`lib/core/map_layout.dart`（画面配置プリセット）や Blender の Application Templates と同じく、**プリセット自体が機能をロックすることはない**。

- 内部的には各ボタン・メニューの表示フラグ（`UiVisibilityConfig`）、背景地図レイヤ（`BaseMapService.layers`）、公式データ（`OfficialLayerService.enabledIds`）、3D地形精度（`terrain_high_precision`）、GNSS品質ゲート（`GnssQualityGate`）、軌跡間引き（`TrackRecordingSettings`）がそれぞれ独立した設定として保存される。
- 用途プリセット（`RolePreset`）を選ぶと、現場に最適な組み合わせ（レシピ）がそれらへ一括反映される。
- 適用後も「一般設定 → 用途プリセット → ボタン・設定メニューの表示調整」や各設定画面から 1 項目ずつ自由に変更でき、変更中は「個別調整中」バッジと「プリセット既定に戻す」ボタンが表示される。

---

## 2. 組み込みの5つの用途プリセット

| プリセット | UI表示（引き算） | 背景地図レイヤ（下→上） | 公式データ（`System`） | 3D地形精度 | GPS・測位設定 | 一括DL既定（半径 / 推奨上限Z / 公式データ） |
|---|---|---|---|---|---|---|
| **標準** (`standard`) | すべて表示 | 地理院 標準地図 (100%) | なし | 標準 (10m) | 足切りなし・既定軌跡 | 1.0 km / z17 / OFF |
| **猟師・狩猟** (`hunter`) | **作図(ペン)非表示・属性表ボタン非表示・詳細設定折りたたみ**（手袋での誤操作防止） | 地理院 淡色地図 (100%) + 等高線 (`multiply` 100%) | 森林計画対象森林（林班・国有林/民有林） | **標準 (10m)**（省通信・省電力） | 徒歩向け軌跡（2秒・2m・±50m・100km/h） | 2.0 km / **z16** / **ON** |

## 3. 安全設計（チュートリアル・操作中のツール保護）

1. **操作中ツールの自動退避**:
   - 作図（ペン）・GPS・計測ツールを握っている状態でそのツールを非表示にした場合、自動的に移動ツール（`Pan`）へ持ち替える。
   - 属性テーブルを開いた状態で属性テーブルボタンを非表示にした場合、開いている属性テーブルを自動で閉じる。
2. **チュートリアル実行中の保護**:
   - 対話型チュートリアル（`tutorialProvider != null`）の実行中は、`UiVisibilityConfig` の設定に関わらず `Pen`・`Select`・`GPS`・`AttributeTable`・全設定カテゴリーを一時的にすべて表示する。これにより、猟師プリセット等のままチュートリアルを開始してもハイライト対象ボタンが消えて進行不能になることがない。
3. **設定画面の折りたたみ解除**:
   - 詳細設定カテゴリー（外部機器・レイヤスタイル）を折りたたんでいるときも、設定画面下部に「すべての設定カテゴリーを表示」タイルを出し、1タップでその場で展開できる。

## 4. オフライン一括ダウンロードとの連動

`BasemapDownloadSettingsDialog`（「地図・タイル → 地図の一括ダウンロード」）では、現在のプリセットと有効レイヤに応じて以下を行う:

- **レイヤ単位の選択チェックボックス**: 現在表示中の背景地図レイヤに加え、`System` で有効化されている公式ベクトルタイル（森林計画対象森林の林班界 MVT 等）も個別にチェック ON/OFF して必要な地図だけを落とせる。
- **推奨上限ズームの自動初期値**: たとえば猟師プリセットでは初期上限ズームを `z16`（半径 2km）に抑えることで、`z18` まで無自覚に落とした場合と比べてタイル枚数を約 1/16 に削減する（スライダーで手動引き上げも可能）。
- **公式ベクトルタイルの MBTiles 永続化**: 取得した公式 MVT（`.pbf`）は `official_<id>.mbtiles` として端末内に保存されるため、事前ダウンロードしておけば携帯圏外の山中でも国有林・林班界の表示とタップ属性確認がそのまま動作する。
